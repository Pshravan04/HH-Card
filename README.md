## 📸 Overview

The **HH Goa 2026 ID Generator** is a sleek, client-side web application designed to help developers, designers, and founders generate their official hacker house credentials. Upload your photo, define your tech stack, generate your builder class, and get an instantly shareable, branded ID card.

## ✨ Features

- **Pill-Shaped UI Aesthetics**: A stunning, modern interface utilizing deep forest green, hot pink, and golden yellow.
- **Privacy First**: All image cropping and processing happens strictly on your local device. No images are uploaded to any server.
- **Auto Image Masking**: Seamlessly maps uploaded portraits into a clean, circular crop.
- **Dynamic Personalization**: 
  - Select your role (e.g., *Developer, Designer, Founder*)
  - Declare your tech stack (e.g., *React, Rust, Solidity*)
  - Enter a Team / Squad name to bring your friends together!
- **Interactive 3D ID Card**: Built with GSAP, the final ID card features an interactive 3D rotation hover effect.
- **Instant Export**:
  - `DOWNLOAD PNG`: Generates a high-quality image of your card using `html-to-image`.
  - `POST TO X`: 1-click share intent pre-loaded with the `#FrameInGoa` hashtag.

## 🛠 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **Animation**: [GSAP (GreenSock)](https://gsap.com/)
- **Utility**: [html-to-image](https://github.com/bubkoo/html-to-image) for seamless client-side rendering of DOM elements to PNG.

## 🚀 Getting Started

To run the generator locally, simply follow these steps:

### Prerequisites

Make sure you have Node.js (v18+) and npm installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/Pshravan04/HH-Card.git

# Navigate into the directory
cd HH-Card

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to start building your ID!
